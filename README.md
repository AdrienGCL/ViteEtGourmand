# ViteEtGourmand
ECF Développeur web et web mobile Studi - Juin 2026

Application web réalisée pour le compte de l'entreprise fictive Vite & Gourmand, traiteur basé à Bordeaux. Le but de l'application est d'augmenter la visibilité de l'entreprise et de présenter leurs menus à un plus large public. La fonctionnalité phare de l'application est la possibilité de commander directement depuis celle-ci.

## Pour commencer

L'application est toujours en cours de développement. Certaines fonctionnalités n'étant pas encore développées une grande partie du parcours utilisateur est actuellement simulée.

### Pré-requis

- PHP 8.2.12

## Démarrage

Copier les fichiers en local et exécuter le fichier ./index.php via un serveur local (ex: Apache).

## Fabriqué avec

- Bootstrap.css
- Visual Studio Code
- Chatgpt (!!! Pour l'élaboration des plats, menus, avis et les illustrations uniquement. !!!)
